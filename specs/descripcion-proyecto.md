# fwskills — Descripción del proyecto

fwskills es un repositorio comunitario de skills para agentes de IA publicado en dos formas simultáneas: como sitio web estático construido con Astro 7 (`frontend/`) y como paquete de npm (`cli/`, invocado como `npx fwskills add <skill>`). El sitio presenta la landing, el catálogo completo de skills y la documentación; el CLI instala en el proyecto del usuario cualquiera de esas skills sin que deba copiar archivos manualmente. Cada skill es una carpeta que contiene un `SKILL.md` cuyo frontmatter declara exactamente ocho campos (`name`, `description`, `category`, `version`, `author`, `tags`, `compatibility`, `featured`), y el catálogo, sus páginas de detalle, el índice de búsqueda y el `sitemap.xml` se derivan de esas carpetas durante el build, de modo que publicar una skill nueva —o una categoría nueva— no exige modificar el frontend. La orientación del proyecto es deliberadamente comunitaria: cualquier persona puede contribuir con una skill respetando la misma plantilla de frontmatter, y el valor del repositorio reside en la variedad y el mantenimiento de esa colección compartida y no en un catálogo curado de manera centralizada. Como consecuencia de ese enfoque, la fricción de contribución se mantiene baja a propósito y la validación de los datos ocurre en tiempo de compilación: una `SKILL.md` mal formada rompe el build, que es el comportamiento previsto. El sitio es 100 % estático —sin backend, base de datos, autenticación, panel de administración, comentarios, valoraciones ni telemetría— y los únicos datos que podrían variar en el tiempo (estrellas, colaboradores, releases y fecha de actualización) también se resuelven en tiempo de build.
